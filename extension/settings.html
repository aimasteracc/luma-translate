ブラウザの拡張機能メニューから Luma を固定すると、すぐに開けます。

01

翻訳エンジン

使い慣れた API を、あなたのキーで。

例: https://api.example.com/v1
/chat/completions は自動で追加します。HTTPS または localhost を指定してください。

利用できるモデル名を指定できます。

02

読み方の設定

いつもの読み方を、初期設定に。

ページ全体の翻訳 Alt + Shift + L
選択範囲の翻訳 Alt + Shift + S
Mac では Alt は Option キーです。割り当てはブラウザの拡張機能ショートカット設定で変更できます。

03

翻訳をカスタマイズ

必要なルールだけ、少しずつ。

辞書は翻訳時の指示として渡します。訳語の完全な一致を保証するものではありません。

ここに入力したルールは、翻訳する文章とともに API に送信します。

04

サイトとデータ

自動翻訳する場所も、自分で選ぶ。

閲覧中のページの Luma パネルから追加できます。サイトごとにアクセス許可を求めます。

送信するもの、保存するもの。

翻訳する文章・翻訳先・辞書・カスタムプロンプトを、設定した API に送信します。API キーは接続先への認証にだけ使用し、ページ側には渡しません。

訳文のキャッシュはバックグラウンド処理のメモリに最大 100 件だけ保持します。永続的な閲覧履歴や解析データは保存しません。API 側での取り扱いは各プロバイダーの規約に従います。翻訳には API 利用料金が発生します。

接続確認では短い文章を API に送信します。
