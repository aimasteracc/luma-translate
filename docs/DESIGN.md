# Luma design

Approved concept: Luma Translate, 2026-11-02.

The article stays the user's article. The extension adds translations and its own
compact controls, without replacing the site's visual identity.

- Paper: `#f8f7f3`; surface: `#fffefa`.
- Ink: `#183d35`; primary: `#144d43`; translation tint: `#eaf2eb`.
- Borders: `#dbe0d7`; focus: `#a76422`; errors: `#a12e25`.
- Brand: local Baskerville / Palatino / Georgia.
- Japanese UI: local Hiragino / Yu Gothic / Meiryo.
- No external font requests. No decorative dashboard metrics.
- 44px controls; visible keyboard focus; labeled selects and switches.
- Persistent panel footer; body scrolls on short screens.
- Motion limited to brief color/position feedback; reduced-motion support.
- Errors and progress appear next to the actions that caused them.
- Provider, glossary and custom instructions are grouped in settings.

The design uses the installed UI UX Pro Max guidance, adapted to a reading tool
rather than a marketing landing page. Native line icons and a small leaf mark are
code-generated assets, not copied product logos.
